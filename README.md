# SaveMOD — Telegram Business Constructor + Module

Современный Telegram-бот на **Node.js + grammY** в духе SaveMOD:
конструктор управляемых ботов (Bot API 9.6 «Managed Bots») + универсальный
бизнес-модуль для каждого созданного бота.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `constructor.js` | Один-единственный бот-конструктор. Inline-меню «Мои боты», создание через `t.me/newbot/...`, БД пользователей и созданных ботов, авто-запуск модуля для каждого нового бота. |
| `module.js`      | Универсальный модуль, который подключается к **любому** созданному боту. Реализует: <br>• уведомления о редактировании/удалении сообщений собеседника <br>• сохранение исчезающих фото / voice / video_note <br>• `.help` и заготовки для остальных точечных команд <br>• inline-меню «Описание команд», «Профиль», «Настройки» как на скриншотах. |
| `.env.example`   | Пример переменных окружения. |

## Используемые возможности Bot API

- **7.2** (март 2024) — `business_connection`, `business_message`, `edited_business_message`, `deleted_business_messages`
- **9.0** (апрель 2025) — `readBusinessMessage`, `deleteBusinessMessages`, `BusinessBotRights`
- **9.6** (апрель 2026) — `https://t.me/newbot/<manager>/<suggested>?name=<name>` для создания управляемого бота и update `managed_bot`

## Запуск

```bash
git clone … && cd savemod
cp .env.example .env       # вставь CONSTRUCTOR_BOT_TOKEN и CONSTRUCTOR_BOT_USERNAME
npm install
npm run constructor        # модули поднимутся автоматически
```

Если хочешь поднять модуль вручную для уже существующего бота:

```bash
MODULE_BOT_TOKEN=123456:AA-... MODULE_BOT_USERNAME=MyBot node module.js
```

## Что показывает интерфейс

1. **/start** — приветствие + главное меню (Мои боты / Профиль / Настройки / Канал / Инструкция / Premium).
2. **Мои боты** — список созданных ботов c количеством подключений; «➕ Создать бота» / «🔗 Добавить существующего».
3. **Создание бота** — двух-шаговый мастер (username → display name) → системная кнопка Telegram открывает окно «Создание бота».
4. После создания **конструктор получает `managed_bot` update с токеном**, пишет бота в БД и **автоматически запускает `module.js`** как дочерний процесс.
5. Внутри созданного бота: меню как на скрине 3 (Скопировать @username, Описание команд, Профиль, Инструкция, Канал, Premium-доступ, Настройки) и подменю точечных команд (скрин 4).

## Принципы кода

- **Inline-only UI** — каждое меню редактирует своё же сообщение (`editMessageText`), а не плодит новые. Минимализм.
- **MarkdownV2** везде с безопасным эскейпом.
- **Без `Reply Keyboard`** — современный Telegram-стайл.
- **SQLite (better-sqlite3)** — синхронные prepared-statements, WAL.
- **Allowed updates** объявлены явно — иначе Telegram не присылает Business-апдейты.
- **Один процесс на бота** — конструктор сам форкает `module.js`; падение модуля одного бота не валит весь сервис.
